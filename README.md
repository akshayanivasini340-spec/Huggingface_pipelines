# Hugging Face NLP Pipeline Project

This project demonstrates the use of Hugging Face Transformers pipelines for different Natural Language Processing (NLP) tasks.

## Features

The project includes the following NLP tasks:

- Sentiment Analysis
- Text Summarization
- Translation
- Question Answering
- Text Classification

## Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Pandas
